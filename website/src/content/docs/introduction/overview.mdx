**See which content types are inside a text file, and where.** TypeSeg labels regions of code, markup, data, and encodings across **35 textual content types**. It shows where each type starts and ends, including in mixed or malformed text.

**No GPU required.** In our research-runtime benchmarks, U-Net processed **about 292,000 characters per second on CPU**. With a consumer-grade **RTX 5070 laptop GPU**, we measured **4.8 million characters per second**—about **4.8 MB/s for ASCII text**. Inference runs locally.

A file detector such as [Magika](https://securityresearch.google/magika/introduction/overview/) can identify textual files before TypeSeg labels their internal regions.

Select a region to inspect its source. [Use cases](../../security/analysis-platforms/) include text inspection, content-specific analysis, and dataset review.

## In your terminal

Inspect mixed text directly from the command line:

```bash
pip install typeseg
typeseg --model fast file.txt
```

<TerminalExample />

The [CLI guide](../../cli/command-line/) covers models, piped input, and output formats.

## Highlights

- **Mixed and malformed text.** Labels content types even when tags are missing or syntax is incomplete.
- **Accuracy across 35 content types.** U-Net achieved **94.9% dense F1** on 875 human-labeled files covering all 35 types. [Evaluation details](../../security/performance/).
- **Small models, local inference.** U-Net has 1.52M parameters and runs on CPU or GPU.
- **Character-level locations.** Each segment includes a content type, start and end offsets, and confidence. [Output format](../../core-concepts/understanding-the-output/).
- **Python, CLI, and browser.** Try the [Python package](https://pypi.org/project/typeseg/), [command-line tool](../../cli/command-line/), or [browser demo](../web-demo/). Demo text stays in your browser.
- **Open source.** Code and general checkpoints are available under Apache 2.0. [Research and citation](../../resources/research/).

Rates are warmed research-runtime measurements on an AMD Ryzen AI 7 350 and an RTX 5070 laptop GPU (85 W). [Measurement details](../../security/performance/).
